# 织音机

在浏览器本地读取歌声合成、MIDI 与 FL Studio 工程，生成带歌词的五线谱与简谱或器乐总谱，直接预览和下载 PDF。原路径 `projects/vocal-score/` 保持不变。

开源协议：GNU Affero General Public License v3.0 或更新版本（[LICENSE](LICENSE)）。源代码：<https://github.com/lsy-404/tiny/tree/main/apps/vocal-score>。

在仓库根目录使用 Node.js 22.13 或更新版本与 pnpm 10.34.6：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm check
```

单独开发工具界面时，在仓库根目录运行 `pnpm exec vite apps/vocal-score --config apps/vocal-score/vite.config.js`。门户预览服务器通过 `node test/vocal-score/server.js` 启动。工具使用 Vue 单文件组件和 Vue I18n；生产构建会把静态文件集成到 `dist/projects/vocal-score/`，无需后端。运行依赖与字体随构建包含，不从 CDN 加载。

功能：

- 输入格式：Synthesizer V（.svp、.s5p）、ACE Studio（.acep）、VOCALOID（.vsqx、.vpr、.vsq、VOCALOID MIDI）、UTAU（.ust）、OpenUtau（.ustx）、CeVIO（.ccs）、VoiSona（.tssln）、DeepVocal（.dv）、Piapro Studio NT（.ppsf）、MusicXML（.musicxml、.xml、.mxl）、UtaFormatix（.ufdata）、标准 MIDI（.mid）与 FL Studio 12 及以上（.flp）。除 SVP 外均为 Beta，解析器在 `src/lib/importers/`，按需加载。格式处理参考 UtaFormatix3（Apache-2.0），ACE Studio 与 DeepVocal 另参考 LibreSVIP，VoiSona 参考 valuetree-ts。
- 器乐总谱（MIDI、FL Studio、无歌词 MusicXML）：按乐器名、FL 播放列表轨道名或 MIDI 音色识别乐器，按木管、铜管、打击乐、键盘、人声、弦乐排序；按乐器与音域选高音、中音或低音谱号；同起止的音符写成和弦；General MIDI 鼓写在打击乐谱表上；“合并分散独唱”只作用于人声声部，器乐声部保持各自的谱表。FL Studio 只读取第一个编排，静音的通道与轨道仍导入并给出提示。

- 打开时显示启动画面，只准备工具运行所需的资源：制谱引擎、字体、歌词编辑器代码，并预热歌词匹配 Worker（载入拼音词典）与 PDF 导出 Worker；某项超过 10 秒仍未完成时可先进入。浏览器中保存的工程在启动画面之后恢复并排版，显示常规的排版进度。
- 多文件导入、声部选择、调号、移调和节奏网格。声部列表可拖动或用上下按钮排序并直接改名，谱面按此顺序排列；器乐工程导入时先按乐器排序。
- 网格对齐后，原本互不重叠的声部保持单声部：过短的音符被裁短或并入相邻音符（保留前一音符的字、较长音符的音高），不会变成第二声部。
- 首次打开为空白。文件原始内容、修改后的歌词及每份文件的转换、排版和纸张设置保存在当前浏览器的 IndexedDB，可移除；清除浏览器数据也会删除这些内容。
- 简中、英文、日文、韩文界面；语言与主题偏好保存到当前浏览器。用户标题、声部名和歌词保持原文。
- 根据音符推测调性（音级分布匹配，并按调外音时长扣分，避免五声音阶旋律被误判为关系小调的属调）；按目标音区自动计算整体移调并同步更新调号。会显示音域变化和仍超出目标范围的音符数，允许手动修改。
- 合并分散独唱（只作用于人声声部）：同一演唱者把不同段落分在多条轨唱（轨 A 唱前半、轨 B 唱后半）时，后面的声部与前面某一声部同时发声不超过“允许重叠”（默认 5%，可选不允许、2%、10%、20%）就按整句并入该声部，重叠的乐句留在原声部；和声等大量同时发声的声部保持完整。候选声部按同时发声最少、同一声库、音区相近、位置靠上依次选择。默认只合并同一声库，可选允许合并不同声库。
- 显示演唱者（声库，默认关闭）：声部名后附声库名，合并后或音符组换声库处在谱面上方标注新声库；声部列表也显示声库。可读取 SVP（按音符组）、S5P、USTX、UST、VSQX、VPR、DV 的声库名；ACEP 只保存歌手编号，不显示。
- 识别完全相同的重复乐段并提示歌词差异；保留完整的小节和歌词。
- 根据所选音轨展示多个和弦候选，可选择在谱面标记。匹配度表示音高集合的匹配，不能当作正确率。
- 歌词修正：把整首正确歌词粘贴进空白框即可，不用管顺序、分段和换行；同时对齐所有声部（同一句由多个声部分唱也可以），按拼音读音逐字匹配，多音字、她/他/祂/TA、“心声/新生”式异写、重叠字与续唱韵母、a/ha 等哼唱都能处理。粘贴框里逐字画线：蓝色实线将修正、绿色已一致、橙色虚线读音不同、红色波浪线谱中没有；光标所在的字显示它对到哪个声部的哪个音符；各声部显示修正数与未对上的小节，点小节号跳到对应音符。可写入原文或拼音，一次修正全部声部并可撤销。下方按乐句排列的格子可逐字修改，显示小节、拍、音高与拍数时值；可清空并还原整个声部。歌词匹配在 Worker 中运行（只发送各声部歌词，输入期间只保留最新一次请求），不支持 Worker 的浏览器在页面上运行；一次修正数百个音符只触发一次重新排版与保存。
- 可直接点选谱面上的标题、页眉、署名、声部名或歌词进行编辑；也可按拼音匹配现有歌词补入汉字，显示匹配位置并处理多音字歧义。
- “考虑调校参数”默认关闭，关闭时忽略音分与音高曲线；打开后识别音分与手动音高曲线（SVP 的平铺控制点与成对写法都可读取），达到阈值时按代表偏移修正半音，显示修正前后及残余音分；剩余音分提示按声部汇总为一条。Synthesizer V 的自动音高（systemPitchDelta）只在调校页作参考：显示曲线数、中段偏离达到阈值的音符数和每个修正音符的自动音高，不参与修正。动态曲线采用中段采样，非线性曲线为近似；滑音、颤音参数作为参数展示。
- 按拍拼写节奏：拍内用单一时值（含附点），跨拍用连音线，半小节内的切分四分音符保持完整；八分与更短音符按拍连杠，4/4 等偶数拍中纯八分音符按半小节连杠，复合拍按附点四分分组；简谱减时线随连杠相连。
- 合并连续音符（默认自动）：自动逐个判断续唱音：同音高的 `-`/`+` 并入前一音符，重唱前字韵母（如 zou 后的 ou）视为同一音节；十六分音符以内、结束该音节的短音，朝下一个音继续或落在下一个音上的是滑音，折返的是装饰音，按“滑音与装饰音”写成滑音线、倚音、并入前一音或保留音符；更长的不同音高续唱音保留为花腔。也可选不合并或固定档位：低把同音高的 `-`/`+` 延长音并入前一音符；中还把韵母续唱音视为延长，同音高合并、不同音高改为延长线，并容忍一格节奏网格的空隙；高再吸收十六分音符以内的续唱音。
- 记谱风格：预设流行旋律谱（自动合并、滑音线、连线加延长线、括号三连音；默认）、合唱谱（倚音、连线加延长线）、简洁（并入前一音、连线、重复三连音省略数字、摇摆记法）与原样（不合并）；各项也可单独选择，改动后显示为自定义。花腔记法可选延长线、连线或两者（连线跨小节从首段画到末段，同一时值的和弦只在首音上标记）；三连音标记可选括号与数字、只写数字或重复时省略（相邻相同节奏的三连音只在前两组标数字）；摇摆记法把三连音拍中只用拍首与后三分之一的长短音写成平直八分音符，在谱首标注 Swing（♫ = ♩♪³）并写入 MusicXML 的 swing 播放信息，其他拍的平直八分音符给出提示。简谱同样画连线、滑音线、倚音（含高低音点）并按三连音标记取舍括号与数字。
- 转换提示（网格调整、并入的过短音符、多声部等）按声部完整列在“乐段与和声分析”页，谱面上方只显示条数按钮，点按即打开该页；错误仍在谱面上方显示。手机上点按侧栏以外的区域即可收起侧栏。
- 识别三连音（默认开）：每个四分拍在节奏网格与三连网格（八分网格用八分三连音，十六分及以上用十六分三连音）之间择优，明显落在三连位置时才写成三连音，直拍不受影响；五线谱带“3”括号，简谱在组上方标“3”。仅用于 x/4 拍号。
- 识别转调（可关闭）：按小节音级匹配调号集合，持续的转调写入新调号，零星临时记号保持为临时记号。
- 速度标记取整，同一位置的成对速度点只保留一个，连续小幅渐变合并为 rit./accel. 与终点速度。
- 字体、歌词/标题/页眉字号、每页页眉、首页 by 署名、页码、小节号、页边距（0–30 mm，预览与 PDF 一致）。
- 按纸张连续预览排版页面并直接下载 PDF，支持 A4、Letter、Legal、A3、A5 和横竖方向；也可导出 MusicXML 与谱面 SVG。
- 播放走带：谱面下方的播放栏按谱播放，光标在预览页面（与下载的 PDF 同一版面）上逐音移动，五线谱与简谱都有；光标按听到的时刻（音频输出时间戳加页面时钟）定位，沿每行谱用单调三次曲线经过各音符，跨小节线不停顿，只更新光标自身并用 transform 亚像素移动。换行时自动翻到光标所在处，播放过一次后点击谱面即可跳到该处，空格键播放/暂停。内置钢琴音色由浏览器按弦振动合成（无采样文件，worker 预渲染各音高），首次播放约 0.3 秒准备。工程文件不含人声音频，推荐“打开音频”：选择合成器导出的 WAV/MP3 等文件（仅在本机读取，300 MB 以内），光标跟着真实人声走，钢琴自动关闭、可随时打开对照；从工程开头导出的音频偏移为 0，否则可调“音频偏移（秒）”。导出的 SVG/PDF 不含走带标记。
- 歌曲：打开或拖入的音频成为独立的“歌曲”，列在工程文件下方，单独保存在本浏览器（IndexedDB `audio` 存储），不随工程删除。点击歌曲挂到当前工程，再点一次（或播放栏的 ⏏）解除挂接；一首歌曲可挂到多个工程（如主唱、和声分开的工程），偏移按工程各自保存；播放栏也可从已有歌曲中挂接。拖入的音频优先挂到同名工程，否则挂到尚无歌曲的当前工程。删除歌曲会从所有工程解除。
- 拼音补字：歌词里写成拼音的字（如“音 yue”“画 ye”、整轨拼音的和声）在谱面上有橙色虚线，点开即弹出候选汉字：其他声部同一时间唱的同音汉字、全曲前后同读音的汉字（按前后字的读音相似度排序，显示小节与上下文）、与相邻字组成词语的字（音 + yue → 乐），另有全部同音常用字（GB 2312 一级字）。可勾选同时替换其他声部同一位置的同音拼音，也可把本声部所有与其他声部同时演唱的拼音一次填成汉字。候选在歌词 worker 中计算。 标题下的“N 处拼音可补汉字”按钮按阅读顺序逐个打开。
- 自校：导入工程时，若本曲自身就能补全拼音（其他声部同一时间唱的同音汉字，或前后同句且相邻字读音也对得上的汉字），自动弹窗询问；按声部列出每处的小节与前后文，默认选中本曲来源的字，可逐字改选其他候选或保留拼音，再“全部采用”。采用后标题旁有“已补 N 处 · 撤销”。歌词面板“原文/拼音”旁的“自校”按钮可随时再次检查。
- 使用 Platform Kit Fluent 的样式包，支持浅色和深色外观。

最后一小节以终止线结束（五线谱与简谱）。可导入 512 MB 以内的 FL Studio 工程，其他格式 100 MB 以内。声乐连线画在谱表上方；花腔延续到新一行而该行没有歌词文字时，五线谱仍保留歌词行，延长线不会压到音符或下一行谱表（只影响显示，导出的 MusicXML 不变）。五线谱支持同轨复音；简谱暂要求每个输出声部内没有重叠音符。转换不生成歌声音频，也不修改磁盘上的原始工程。预览直接显示矢量谱面，页边与缩放和 PDF 一致；下载时按 220 DPI 生成 PDF 页面图像，PDF 内文字不可搜索，需要可编辑或矢量内容时可导出 MusicXML 或 SVG。所有工程、原始文件副本和设置仅保存在当前浏览器，不会上传到服务器。

完整验证：`pnpm check`。设置 `SVP_SAMPLE_FILES` 为以分号分隔的本地 `.svp` 文件路径可增加真实工程转换验证。`test/vocal-score/formats.browser.mjs` 在浏览器里导入各格式，`FORMAT_SAMPLE_FILES`（分号分隔，任意支持格式）可加入本地真实工程；`FLP_SAMPLE_DIR` 指定 FL Studio 样本目录。样本只在本地读取，不进入仓库。浏览器回归脚本位于仓库根目录 `test/vocal-score/`，通过外部安装的 Playwright 执行；使用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块，使用 `PREVIEW_URL` 指向已构建门户中的 `/projects/vocal-score/` 页面。

致谢：感谢奥莉安多提供的样本数据和改善建议。

第三方许可位于 `public/vendor/`（总览见 `THIRD-PARTY.txt`），构建后也包含在 `dist/projects/vocal-score/vendor/`，界面侧栏底部有链接。原始用户工程和生成的歌曲文件不进入源代码或部署资源。
